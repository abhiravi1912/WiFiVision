THE PROCESS

How WiFi-Vision works

Human movement changes the wireless channel. The ESP32 captures those changes as CSI, which is then processed to identify activity.

  1. 01

    Transmit

    An ESP32 sender continuously broadcasts Wi-Fi packets across the space.

  2. 02

    Interact

    Human movement physically disturbs the propagating wireless wavefronts.

  3. 03

    Capture

    A second ESP32 receiver records the resulting Channel State Information.

  4. 04

    Recognize

    The CSI pattern is processed to classify the current activity.
